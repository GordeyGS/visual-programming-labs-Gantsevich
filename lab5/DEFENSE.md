# Защита лабораторной №5 — TypeBot

## Что показать

1. Docker Compose: Builder, Viewer, PostgreSQL, Redis и Mailpit запущены.
2. В Builder открыть `lab5-gantsevich-student-helper` и показать граф.
3. Показать переменные `Имя`, `Группа`, `Статус`, `Факт`, `Вопрос`.
4. Открыть Condition, который сравнивает группу с `СДП-ИИ-241`.
5. Открыть HTTP Request: GET-запрос к `https://catfact.ninja/fact` записывает `data.fact` в переменную `Факт`.
6. Показать изменённую сине-зелёную тему и русские системные сообщения.
7. Открыть опубликованного бота и пройти один полный диалог.
8. Показать JSON-экспорт и историю Git-коммитов.

Опубликованный бот открывается по адресу <http://127.0.0.1:8081/lab5-gantsevich-student-helper> при запущенном Docker Compose.

## Как работает сценарий

Стартовое событие открывает приветствие. Text Input сохраняет имя и группу пользователя в переменные. Condition направляет студента СДП-ИИ-241 по основной ветке, а пользователя другой группы — по альтернативной. Обе ветки приходят в меню.

Из меню доступны расписание, памятка по лабораторной, внешний API и собственный вопрос. Памятка демонстрирует Set Variable. Ветка с API делает GET-запрос, извлекает поле `fact` и показывает результат. Jump возвращает пользователя в меню без дублирования блоков.

## Возможные вопросы

**Зачем нужна переменная?** Она хранит ответ пользователя и позволяет повторно использовать значение в сообщениях, условиях и интеграциях.

**Как работает Condition?** Блок сравнивает значение `Группа` со строкой `СДП-ИИ-241`. Совпадение идёт по именованному выходу, остальные значения — по fallback-выходу.

**Чем Builder отличается от Viewer?** Builder нужен для редактирования графа, а Viewer запускает опубликованную версию для пользователя.

**Зачем PostgreSQL и Redis?** PostgreSQL хранит проекты, пользователей и результаты, Redis поддерживает служебные операции и временные данные TypeBot.

**Что хранится в JSON-экспорте?** Группы, блоки, связи, переменные, тема, настройки и метаданные сценария.

**Какие ограничения у бесплатного облачного тарифа?** Ограничено количество чатов в месяц и некоторые командные функции. В лабораторной используется локальная self-hosted версия, поэтому она не зависит от облачного лимита чатов, но требует самостоятельного запуска и обслуживания.
