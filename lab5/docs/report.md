# Лабораторная работа №5 — чат-боты

**Студент:** Гордей Ганцевич  
**Группа:** СДП-ИИ-241

## Выбранный трек

Выбран трек C — TypeBot. Платформа развёрнута локально через Docker Compose. Для работы используются Typebot Builder, Typebot Viewer, PostgreSQL, Redis и локальный почтовый интерфейс Mailpit.

## Бот

Название: `lab5-gantsevich-student-helper`.

Бот представляет собой русскоязычного помощника студента. Он приветствует пользователя, запрашивает имя и группу, предлагает выбрать тему вопроса, использует переменные и условное ветвление, а также выполняет HTTP-запрос.

## Освоенные элементы

- текстовые сообщения;
- ввод текста;
- кнопки;
- переменные;
- условие Condition;
- HTTP Request;
- переходы между группами;
- настройка темы;
- публикация web-версии;
- экспорт TypeBot в JSON.

## AI-промпты

1. «Спроектируй русскоязычный сценарий TypeBot для помощника студента с вводом имени и группы».
2. «Добавь условное ветвление по выбранной теме вопроса и понятный fallback».
3. «Предложи безопасный публичный API без токена для демонстрации HTTP Request».
4. «Подготовь объяснение переменных, условий и переходов для защиты лабораторной работы».

## Выводы

В ходе работы освоена визуальная сборка чат-бота в TypeBot. Переменные позволяют сохранять ответы пользователя, Condition направляет диалог по разным веткам, а HTTP Request связывает сценарий с внешними сервисами. Публикация во Viewer превращает визуальную схему в доступный web-чат, а JSON-экспорт позволяет хранить и версионировать структуру бота в Git.
