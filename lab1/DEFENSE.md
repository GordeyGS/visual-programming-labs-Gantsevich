# Краткая защита лабораторной №1

**Что сделано:** создан Git-репозиторий и смоделирован процесс ремонта устройства в сервисном центре четырьмя способами: BPMN, UML Activity, Sequence Diagram и Flowchart.

**BPMN:** показывает весь бизнес-процесс. Круг — начало/конец, прямоугольники — задачи, ромбы — шлюзы. XOR используется для выбора «да/нет», AND — для параллельных действий.

**UML Activity:** показывает логику участка диагностики и принятия решения о ремонте. Есть начальный узел, действия, решения и конечный узел.

**Sequence Diagram:** показывает обмен сообщениями между клиентом, администратором и мастером. Блок `alt` показывает альтернативы, `loop` — повторяющееся тестирование.

**Flowchart:** обычная блок-схема алгоритма обработки ремонта с проверками условий.

**Git diff:** текстовые файлы позволяют увидеть изменения по строкам; для PNG Git показывает только изменение бинарного файла.

**Команды для показа на защите:**
```bash
git log --oneline
git show --stat
git diff HEAD~1 HEAD
```
