## Краткое описание

В Bubble создано веб-приложение **HabitFlow** — трекер привычек. Приложение имеет структуру `header + body + footer`, отдельную страницу управления привычками и полный набор операций CRUD для сущности `Habit`.

Главная страница знакомит пользователя с приложением, а страница `habits` позволяет создавать, просматривать, изменять и удалять привычки без написания программного кода.

## Промпт для генерации каркаса

Промпт, дословно вставленный в AI-агента Bubble:

> Создай приложение на тему «трекер привычек» с названием HabitFlow. Пусть этот сайт будет публичным и не требует регистрации. Страницу обязательно создай по структуре header + body + footer. В header размести название приложения и кнопку «Мои привычки». В body добавь hero-блок, краткое описание приложения, три карточки преимуществ и кнопку перехода к управлению привычками. В footer обязательно укажи строку «ТВП: Ганцевич». Добавь несколько интерактивных элементов, реализующих CRUD для привычек: создание, просмотр, редактирование и удаление. Используй спокойную зелёно-фиолетовую цветовую палитру и адаптивную компоновку.

## Data: сущность Habit

Промпт для проектирования сущности, дословно:

> Предложи сущность для трекера привычек в Bubble. Нужны простое английское имя Data Type и минимум четыре поля разных типов: текст, дата, yes/no и ссылка. Поля должны подходить для демонстрации полного CRUD на одной странице.

Результат: создан Data Type `Habit` со следующими полями:

| Поле | Тип | Назначение |
|---|---|---|
| `name` | text | Название привычки |
| `start_date` | date | Дата начала |
| `is_active` | yes/no | Признак активной привычки |
| `details_url` | text | Ссылка на дополнительные материалы |

Через `App data` вручную добавлены три записи: «Утренняя зарядка», «Чтение 20 минут» и «Пить воду».

## Workflows: полный CRUD

Промпт для генерации UI страницы, дословно:

> Создай новую страницу `habits` для управления сущностью Habit. Сверху размести форму с Input для названия, Date Picker для даты начала, Checkbox для активности и Input для ссылки. Ниже добавь Repeating Group со всеми Habit. В каждой строке покажи поля и кнопки «Редактировать» и «Удалить». Для редактирования используй Popup с теми же полями и кнопкой «Сохранить». Интерфейс должен быть адаптивным и использовать существующие стили приложения.

Реализованы отдельные workflows:

1. **Create** — событие `Button Создать is clicked` выполняет `Data → Create a new thing`, создаёт `Habit` из значений формы и очищает поля.
2. **Read** — `Repeating Group Habits` имеет тип `Habit` и источник `Do a search for Habits`, сортировка по `start_date` по убыванию.
3. **Update** — кнопка «Редактировать» передаёт текущий `Habit` в Popup. Кнопка «Сохранить» выполняет `Data → Make changes to a thing`.
4. **Delete** — кнопка «Удалить» выполняет `Data → Delete a thing` для `Current cell's Habit` после подтверждения.
