## Краткое описание

В Bubble создано веб-приложение **HabitFlow** — публичный трекер привычек без обязательной регистрации. В приложении есть главная страница со структурой `header + body + footer` и отдельная страница `habits`, на которой реализован полный CRUD для сущности `Привычка`.

Главная страница знакомит пользователя с сервисом, показывает преимущества и статистику. Страница `habits` позволяет создавать, просматривать, фильтровать, изменять и удалять привычки.

## Промпт для Bubble AI

В AI-агент Bubble дословно введён один промпт:

> Создай приложение на тему «трекер привычек» с названием HabitFlow. Пусть этот сайт будет публичным и не требует регистрации. Страницу обязательно создай по структуре header + body + footer. В header размести название приложения и кнопку «Мои привычки». В body добавь hero-блок, краткое описание приложения, три карточки преимуществ и кнопку перехода к управлению привычками. В footer обязательно укажи строку «ТВП: Ганцевич». Добавь несколько интерактивных элементов, реализующих CRUD для привычек: создание, просмотр, редактирование и удаление. Используй спокойную зелёно-фиолетовую цветовую палитру и адаптивную компоновку.

AI создал 4 страницы, 146 элементов, 14 workflows и 1 Data Type. После генерации результат был проверен и доработан вручную.

## Исследование идеи

Перед ручной доработкой изучены два официальных материала Bubble:

1. [How to Make Dashboards With Bubble AI](https://bubble.io/blog/how-to-make-dashboards/) — использована идея выводить ключевые показатели отдельными карточками и группировать связанные данные.
2. [Responsive design](https://bubble.io/responsive-design) — применены контейнеры Row/Column, единые отступы и перенос карточек на узких экранах.

## Data: сущность `Привычка`

Bubble AI создал Data Type `Привычка` со следующими полями:

| Поле | Тип | Назначение |
|---|---|---|
| `Владелец` | User | Пользователь или анонимная сессия, которой принадлежит запись |
| `Категория` | option set `Категория` | Тематика привычки |
| `Название` | text | Название привычки |
| `Описание` | text | Дополнительная информация |
| `Статус` | option set `Статус привычки` | Активна, приостановлена или выполнена |
| `Частота` | option set `Частота` | Периодичность выполнения |

Также используются системные поля Bubble `Created Date` и `Modified Date`. Таким образом, структура содержит разные типы данных: `User`, `text`, `option set` и `date`.

В `App data` вручную добавлены две записи:

1. «Осознанное дыхание» — 5 минут дыхательной практики утром, категория «Медитация», статус «Активна», частота «Ежедневно».
2. «Вечерняя прогулка» — 30 минут прогулки без телефона, категория «Спорт», статус «Активна», частота «Ежедневно».

После добавления в Development database находится 22 записи вместе с тестовыми данными, созданными AI.

## Workflows: полный CRUD

На странице `habits` настроено 11 workflows; всего в приложении — 14.

1. **Create** — событие `New Save Button is clicked` выполняет `Create a new Привычка`, скрывает popup и очищает поля (`Reset relevant inputs`).
2. **Read** — список привычек загружается из Development database и показывает записи текущего пользователя/анонимной сессии; есть фильтр по статусу.
3. **Update** — `Edit` открывает popup с текущей записью, а `Edit save` сохраняет изменения.
4. **Delete** — сначала открывается popup подтверждения, затем `Del Confirm Button is clicked` выполняет `Delete Привычка` и скрывает popup. Удаление разрешено только владельцу записи.
