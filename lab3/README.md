# HabitFlow — лабораторная работа №3

Материалы лабораторной по Bubble:

- [`docs/report.md`](docs/report.md) — основной отчёт с промптами и скриншотами;
- [`DEFENSE.md`](DEFENSE.md) — краткая памятка для защиты;
- [`screenshots/`](screenshots/) — подтверждение выполнения шагов в Bubble.

Приложение демонстрирует полный CRUD для сущности `Habit`:

- Create — создание привычки из формы;
- Read — вывод записей в Repeating Group;
- Update — редактирование записи в Popup;
- Delete — удаление выбранной записи.
