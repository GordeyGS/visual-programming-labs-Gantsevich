# Защита лабораторной №6 — Kodular

## Что показать

1. Импортировать `exports/lab6-gantsevich.aia` в Kodular Creator.
2. На вкладке Designer показать `Screen1` и видимую фамилию `Gantsevich`.
3. Показать компоненты Label, TextBox, Button и Web Viewer.
4. На вкладке Blocks открыть событие `GreetingButton.Click`.
5. Объяснить проверку пустого текста через `if / else`.
6. Показать формирование приветствия блоком `join`.
7. Показать ачивку №9: открытие сайта ГрГУ через `UniversityWebViewer.GoToUrl`.
8. Продемонстрировать возврат к форме через изменение свойства `Visible`.
9. Показать `.aia`, скриншоты, отчёт и минимум четыре Git-коммита.

## Как объяснить логику

`GreetingButton.Click` получает свойство `NameTextBox.Text`. Если строка пустая, `ResultLabel.Text` получает сообщение об ошибке. Иначе `join` соединяет три части и формирует персональное приветствие.

`OpenUniversityButton.Click` скрывает `MainLayout`, показывает `WebLayout` и вызывает `UniversityWebViewer.GoToUrl`. `BackButton.Click` выполняет обратное переключение контейнеров.

## Возможные вопросы

**Почему использован Web Viewer?** Он открывает сайт внутри приложения, поэтому пользователь не переходит во внешний браузер.

**Зачем два Vertical Arrangement?** Это позволяет переключать два состояния одного экрана через свойство `Visible`.

**Что хранит `.aia`?** Описание компонентов в `.scm`, визуальные блоки в `.bky` и настройки проекта.

**Какая ачивка выполнена?** Свободная ачивка №9 — Web Viewer.
