# Ачивки лабораторной №6

По сообщениям группы заняты:

- №1 — TinyDB;
- №2 — второй экран и навигация;
- №5 — расширение;
- №6 — генератор QR-кода;
- №8 — уведомления Notifier;
- №10 — простой калькулятор.

Для проекта выбрана свободная **ачивка №9 — Web Viewer**.

Она реализована компонентом `UniversityWebViewer`. Кнопка открывает `https://www.grsu.by` внутри приложения, а кнопка возврата снова показывает форму приветствия.
