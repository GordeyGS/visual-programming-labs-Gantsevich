# Лабораторная работа №6 — Kodular

Мобильное приложение «Приветствие» для Kodular с базовой логикой `if / else` и свободной ачивкой №9 — **Web Viewer**.

## Проект

- имя проекта: `lab6_gantsevich_webviewer`;
- студент: Гордей Ганцевич;
- группа: СДП-ИИ-241;
- фамилия на первом экране: `Gantsevich`;
- выбранная ачивка: №9, Web Viewer.

## Состав

- `exports/lab6-gantsevich.aia` — импортируемый проект Kodular;
- `src/` — исходники проекта App Inventor/Kodular;
- `screenshots/` — подтверждение интерфейса и блоков;
- `docs/report.md` — отчёт;
- `DEFENSE.md` — памятка для защиты;
- `demo/` — браузерная демонстрация поведения приложения.

## Импорт в Kodular

1. Открыть Kodular Creator.
2. Выбрать **Import project (.aia) from my computer**.
3. Загрузить `exports/lab6-gantsevich.aia`.
4. Открыть `Screen1` и проверить вкладки Designer и Blocks.
