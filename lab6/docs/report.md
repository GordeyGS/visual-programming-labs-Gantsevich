## Базовое приложение

Проект `lab6_gantsevich_webviewer` представляет собой мобильное приложение «Приветствие». Пользователь вводит имя и нажимает кнопку. Если поле пустое, приложение выводит «Введите имя!». В остальных случаях формируется строка «Привет, <имя>!».

На первом экране постоянно отображается фамилия `Gantsevich`.

## Выбранная ачивка

**Ачивка 9: Web Viewer.** Приложение содержит кнопку открытия сайта университета внутри приложения. Для возврата к форме используется отдельная кнопка.
