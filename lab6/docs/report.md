## Базовое приложение

Проект `lab6_gantsevich_webviewer` представляет собой мобильное приложение «Приветствие». Пользователь вводит имя и нажимает кнопку. Если поле пустое, приложение выводит «Введите имя!». В остальных случаях формируется строка «Привет, <имя>!».

На первом экране постоянно отображается фамилия `Gantsevich`.

### Компоненты

- `TitleLabel` — заголовок «Введите имя»;
- `NameTextBox` — поле с подсказкой «Ваше имя»;
- `GreetingButton` — кнопка «Поздороваться»;
- `ResultLabel` — вывод ошибки или приветствия;
- `SurnameLabel` — фамилия `Gantsevich` и группа СДП-ИИ-241;
- `MainLayout` — контейнер базовой формы.

### Блоки

Событие `GreetingButton.Click` запускает `if / else`. Условие сравнивает `NameTextBox.Text` с пустой строкой. Для непустого значения блок `join` объединяет «Привет, », имя пользователя и «!».

## Выбранная ачивка

**Ачивка 9: Web Viewer.** Приложение содержит кнопку открытия сайта университета внутри приложения. Для возврата к форме используется отдельная кнопка.

Использованы `OpenUniversityButton`, `WebLayout`, `UniversityWebViewer` и `BackButton`. При открытии скрывается `MainLayout`, показывается `WebLayout`, затем вызывается `UniversityWebViewer.GoToUrl` для адреса `https://www.grsu.by`. Кнопка возврата выполняет обратное переключение видимости.
