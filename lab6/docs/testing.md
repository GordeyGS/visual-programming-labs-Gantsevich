# Проверка приложения

## Базовая логика

1. Запустить приложение и убедиться, что видна фамилия `Gantsevich`.
2. Оставить поле имени пустым и нажать «Поздороваться».
3. Проверить сообщение «Введите имя!».
4. Ввести `Гордей` и снова нажать кнопку.
5. Проверить сообщение «Привет, Гордей!».

## Ачивка 9 Web Viewer

1. Нажать «Открыть сайт университета».
2. Убедиться, что форма приветствия скрылась.
3. Проверить загрузку `https://www.grsu.by` в `UniversityWebViewer`.
4. Нажать «Вернуться к приветствию».
5. Убедиться, что снова отображается основная форма.

## Проверка экспорта

```bash
unzip -t exports/lab6-gantsevich.aia
```

Архив должен содержать `Screen1.scm`, `Screen1.bky` и `youngandroidproject/project.properties` без ошибок целостности.
