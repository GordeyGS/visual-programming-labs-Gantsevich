# Лабораторные работы по технологиям визуального программирования

Репозиторий содержит лабораторные работы по дисциплине «Технологии визуального программирования».

## Лабораторная работа №1

Тема: «Моделирование процессов с использованием Git и визуальных нотаций».

Выбранный бизнес-процесс: **ремонт устройства в сервисном центре**.

Материалы лабораторной находятся в каталоге `lab1`.

## Лабораторная работа №2

Тема: **Node-RED**.

В лабораторной работе реализованы потоки с базовыми и расширенными нодами Node-RED: Inject, Debug, Function, Switch, Change, Template, HTTP Request, MQTT, HTTP endpoints, Dashboard, Telegram, File, Context и WebSocket.

Дополнительно выполнена **ачивка №14 — WebSocket → Dashboard (BTC)** с отображением цены BTCUSDT в реальном времени.

Материалы лабораторной находятся в каталоге `lab2`.
